#  Evergreen Café Ordering System

This project is a web-based ordering system designed for Evergreen Café.  
It allows users to browse a menu, customize drinks, add items to a cart, and generate a receipt with tax.

---

##  Features

-  Full café menu (Hot Drinks, Iced Drinks, Frappuccino)
-  Size selection (S / M / L)
-  Flavor customization (Vanilla, Caramel, Mocha, etc.)
-  Dynamic cart system
-  Automatic subtotal, tax (6%), and total calculation
-  Custom receipt generation
-  Clear cart and clear receipt functionality
-  Responsive design
-  Local assets (logo + background image)

---

##  Technologies Used

- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (Vanilla)

##  How to Run

1. Download or clone the repository
2. Make sure all files are in the same folder:
   - `evergreen-ordering.html`
   - `styles.css`
   - `logo.png`
   - `background.png`
3. Open `evergreen-ordering.html` in your browser

---

##  How It Works

- Menu items are dynamically rendered using JavaScript
- Users select size and optional flavors
- Items are added to a cart stored in memory
- Checkout calculates:
  - Subtotal
  - 6% Tax
  - Final Total
- A receipt is generated and displayed for in-person payment
